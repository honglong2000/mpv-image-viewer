A preconfigured version of mpv to be used exclusively for image viewing that supports enhanced SDR (via 203 nit white level in an HDR container) & Windows natural sorting. I've tested mpv's tonemapping and Nvidia's VSR HDR and found them to be worse visually than enhanced SDR for anime.
I recommend https://github.com/the-database/mpv-AnimeJaNai/releases for anime watching and recommend you use the non-image settings from mpv-image-viewer's mpv.conf to enable enhanced SDR in mpv-AnimeJaNai.
Installation instructions: You can use updater.bat to download mpv.exe or place your own version of mpv.exe in the folder with mpv-image-viewer's contents.
