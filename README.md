A preconfigured version of mpv to be used exclusively for image viewing that supports RTX HDR & Windows natural sorting. I wanted to create an image viewer as close as possible to FastStone image viewer with the advanced capabilities of mpv which is why this was created. All you need to do to get it working is to download all contents of this repository, put it in a folder, and put a copy of mpv.exe in the folder as well. I recommend changing the name of mpv.exe to mpv image viewer.exe to differentiate it as a version of mpv designed exclusively for viewing images.

Credits to https://github.com/PopeyeURS/ulyssescaballes-mpv.config for adding Windows natural sorting to autoload.lua, https://github.com/occivink/mpv-image-viewer for additional scripts, https://mpv.io/ for creating mpv.exe, and https://www.faststone.org/ for initial inspiration.
