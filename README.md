A preconfigured version of mpv to be used exclusively for image viewing (although can still be used for videos if you wish). Supports RTX HDR & Windows natural sorting out of the box. You can easily replace the .exe to update the mpv version but it will likely yield no improvement for image viewing. I created this because I wanted an image viewer as similar as possible to FastStone image viewer with the added capabilities of support for RTX HDR upscaling of images.
