A preconfigured version of mpv to be used exclusively for image viewing (although can still be used for videos if you wish). Supports RTX HDR & Windows natural sorting out of the box. I created this because I wanted an image viewer as similar as possible to FastStone image viewer with the added capabilities of support for RTX HDR upscaling of images. The only thing you have to do to get it working is to put all of these files into a folder and include a copy of mpv.exe in it.
